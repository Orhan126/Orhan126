## ◼ Selected Projects & Technical Work

### ⚙️ Embedded Systems & Microcontroller Development

**ADC-Controlled RGB LED Color Blending System — CH32V003**

- Developed an embedded C application for the WCH CH32V003F4P6 RISC-V microcontroller.
- Implemented ADC-based analog input acquisition.
- Designed an HSV-to-RGB conversion routine for dynamic color generation.
- Configured timer-based PWM outputs to control individual RGB LED channels.
- Worked with microcontroller peripherals and hardware-software interaction.

**Technologies:** C, RISC-V, CH32V003, ADC, PWM, PlatformIO.

### 💻 Operating Systems & Systems Programming

**Priority-Based Round Robin CPU Scheduling**

- Designed and implemented a priority-aware CPU scheduling algorithm in C.
- Incorporated descending priority-based process ordering.
- Applied Round Robin scheduling using a configurable time quantum.
- Calculated waiting time, turnaround time, and average scheduling metrics.

**Memory Allocation Algorithms**

- Implemented First Fit, Best Fit, and Worst Fit memory allocation strategies.
- Explored memory partitioning, allocation decisions, and fragmentation concepts.

**Technologies:** C, Operating Systems, CPU Scheduling, Memory Management.

### 🔌 Digital Logic & Circuit Design

- Implemented Full Adder and Full Subtractor logic circuits.
- Designed and analyzed SR, JK, D, and T flip-flop circuits.
- Applied Boolean algebra and logic simplification techniques.
- Explored combinational and sequential circuit behavior.

**Technologies:** Digital Logic Design, Boolean Algebra, Multisim.

### 🏗️ Software Engineering & System Design
